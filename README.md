# Book_Prefrence_Analysis
## Description

The project is an end-to-end data analysis project covering data collection,cleaning, processing and visualization to provide insights and explore more about book preference across different age groups.

 ## Problem Statement
 There are millions of books available across the globe which has diferent genres and a huge scale of reading communities spread across different age groups.In order to understand the different age groups and their reading preference is a challenge.

## Objective
Through this analysis we analyse the book preference and their ratings as well across different age groups to uncover:
* What genres different age groups prefer
* How actively different age groups engage with books
* What factors influence book ratings
* How reading preferences have changed over time

## 📁 Dataset

Download the dataset from Kaggle and place the CSV files in the `data/` folder:
🔗 https://www.kaggle.com/datasets/arashnic/book-recommendation-dataset
